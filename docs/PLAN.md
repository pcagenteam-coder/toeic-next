## 新仓库组（待用户确认名，暂用下列名）
1. `toeic-next`（公开）：应用壳、UX、引擎、图谱、技巧库、A 层可公开题库、构建与测试、部署脚本
2. `toeic-next-private`（私有）：C 层仅自用题库 + B 层登录可见题库的私有 overlay，构建时合并，绝不进公开仓库历史
3. 旧仓库不新开分支、不合并历史，只在新仓库的 SOURCES.md 里记录旧仓库名、commit 与取用范围

许可三层，绝不混：
- A 可公开：自编、MIT 开源、NGSL/TSL、原创技巧
- B 登录可见：Supabase gated_content 思路，构建时做泄漏检查
- C 仅自用：ETS 转录、新东方等无许可题，私有仓库 + 私有 Release

## 整体架构
- 前端：单文件离线构建优先（toeic-reading 的 build 思路），再接 Cloudflare Pages；PWA + Service Worker（Sesame 的离线能力）
- 引擎层：诊断 / 训练 / 复习 / 攻克 / 模考，接口与存储分离，localStorage 优先、进度码导入导出、Supabase 只做账号页同步
- 数据层：统一 schema（pilot schema 为底）+ 三层加载器，公开构建只含 A，私有构建才叠加 B/C，模考整套记 used、不进训练池
- 同步与安全：密钥永不进仓库，构建时泄漏扫描，私有 Release 只放中间产物与原始素材快照

## 并行三路（已分派，各出 track 方案）

- 题库一路：`tracks/question-bank.md` —— 统一 schema、精确 + 近似去重、剔除清单、批量苦力活清单

三路的接口契约由总计划定，不各自改 schema：题库输出统一 JSON，引擎只读统一 JSON，UX 只读引擎状态与规则卡事件。

## 耗时苦力活（用临时无限量 DeepSeek 4.1，窗口约到 2026-11-03 23:15 CST）

## InstaBox 溢出方案（条件触发，不是默认）
已核实免费额度：1 台、4 vCPU / 8 GiB / 20 GiB 持久盘、200 GiB 存储上限、5 快照、单次连续运行上限约 480 分钟、空闲约 30 分钟自动暂停。
触发条件（任一即考虑分派）：
- 本地批量任务中间文件或去重索引明显超过本地临时空间，或单批跑不完 4.1 窗口
- 需要隔离跑大批量去重 / 向量化 / 审题，不想污染主工作区
分派方式：只建一台临时机，数据放 /data，跑完先打快照、再把结果文件拷回主工作区并暂停或删除机器；C 层数据不上公开端口、不进公开仓库；不做 24/7 托管、不做代理 / 长期服务。
注意：此前 InstaBox 尚无机器，是否建机以触发条件为准，建机前再确认一次用途。

## Hark 会话补正（2026-11-03，从 Hark 导出中找到的非 Sesame 设计讨论）
来源：2026-10-22 至 2026-11-02 的“托业阅读提分应用交接”会话，153 条消息，最后停在剩余任务优先级与交接讨论上，UX v2 前端尚未落地。今天用户发的 9 屏图与该会话 2026-10-24 发出的 m_all.jpg 是同一套 v2 线框稿。
该会话对总计划的关键修正，优先级高于 Sesame 的“答题时藏数字”规则：
- 用户画像：35-40 岁、工作多年、四六级多年未考、忙、有家庭、精力有限、托业商务词不熟、不擅背单词和语法；另有 50 岁以上内部成员；字号要可调、不默认放大；手机 / 平板 / PC 阅读交互要分开，尤其长文左文右题。
- 北极星：每投入 1 分钟涨多少分，且明天愿意再来；v1 惊艳的原因是看得见的智能 + 看得见的进步（大号预测分、任务按分/时排序、答后掌握度与预测分变化、底栏就是公司 App）。
- UX v2 六 / 七条原则：目标常在、每题 3 秒回报闭环（对错 + 用时 → 掌握度 → 预测分）、智能看得见（为什么练这个 + 约 +N 分/时）、先学招再用招、公司 App 外壳、压力只来自时间不羞辱、任何时刻一个主按钮。
- 用户曾明确反对藏过头：线上版“没有计时、没有正确错误、没有沉浸感、入口规则乱”；v1.2 修复为默认显示计时、答完红绿标对错、结算给对题数和用时、恢复邮件 / 群聊 / 审稿场景、首页只留“开始今天的工作”。
- 手册：《新人工作手册》12 章，每章一招，首次遇到由 Dana 递出，60 秒读完、1 道示范、5 题通关盖章，之后只弹“手册第几章”，用熟不再提示，全本放绩效页随时翻。
- 剩余任务（2026-11-02 排序）：先做 63 道答案键人工复核（7 道在模考里）、手册 12 章通读（第 3 章标题与内容不贴）、UX v2 前端、kdeppaei 804 题中文解析；排后是 1,643 道原创难题（先补真考+几百道）、节点复判、词表分档、体积优化、真机与部署最后。
- 数据缺口：公开池约 8 成难度 ≤3、比 Santa 简单，难度当时只是规则粗估未用答题数据校准；技巧近百条却只在错后零星弹出；语法 54 个考点缺 60 秒微讲解。
因此合并 UX 的默认值应改为：默认显示计时、对错、用时、掌握度与预测分变化（3 秒闭环），沉浸靠公司 App 外壳和单主按钮实现，而不是靠藏数字；“考生视角”开关降级为细节展开层，不再作为藏数字的主开关。
