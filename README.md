# toeic-next — Rescheduled Inc.

TOEIC 阅读 Part 5 / 6 / 7 练习应用，只做一个新产品，不再双线开发旧项目。

品牌：Rescheduled Inc.
部署（已确认）：Cloudflare Pages + Supabase，多设备登录同步，本地先行、联网再同步。

## 仓库分工

- `toeic-next`（本仓，公开）：应用壳、UX、引擎、图谱、技巧库、A 层可公开题库、构建与测试、部署脚本。
- `toeic-next-private`（私有）：C 层仅自用题库 + B 层登录可见题库的私有 overlay，构建时合并，绝不进公开仓库历史。
- 旧仓库 Sesame-toeic、toeic-reading、toeic-reading-private 在快照后转为只读归档，不在新仓合并历史，只在 SOURCES.md 里记录取用范围。

## 许可三层，绝不混

- A 可公开：自编、MIT 开源、NGSL / TSL、原创技巧。
- B 登录可见：Supabase gated_content 思路，构建时做泄漏检查。
- C 仅自用：ETS 转录、新东方等无许可题，私有仓库 + 私有 Release，只做内部校准，绝不生成可公开解析。

## 产品要点

- 只练阅读 Part 5（30 题）/ Part 6（16 题）/ Part 7（54 题），现行题型，75 分钟 / 100 题。
- 默认显示计时、对错、用时、掌握度与预测分变化（3 秒回报闭环），沉浸靠公司 App 外壳和单主按钮实现，不靠藏数字；“考生视角”只是细节展开层。
- 会话：5 / 20 / 75 分钟；模式：诊断 / 训练 / 复习 / 攻克 / 模考。
- 目标人群：35–40 岁、工作多年、四六级多年未考、忙、有家庭、精力有限；另有 50 岁以上内部成员；字号可调，不默认放大。
